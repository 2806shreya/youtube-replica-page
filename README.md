A simple YouTube-style webpage built using HTML, CSS, and JavaScript.

## Features

- 🎨 YouTube-like layout with video area and suggested videos
- 🌙 Theme toggle (dark/light)
- 🎥 Hover effects and comments section

## Run locally

1. Clone this repository.
2. Open `/home/runner/work/youtube-replica-page/youtube-replica-page/index.html` in your browser.
